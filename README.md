# htmlcss-bootstrap-layout

Esempio di layout a griglia con Bootstrap 5 e breakpoint responsivi.

## Demo

Apri `index.html` nel browser.

## Tech

- HTML5
- Bootstrap 5 (CDN)

## Struttura

```
.
├─ index.html
└─ README.md
```

## Note

Il layout mostra l’uso delle classi `col-sm-*`, `col-md-*`, `col-lg-*` per gestire le colonne sui vari breakpoint.
